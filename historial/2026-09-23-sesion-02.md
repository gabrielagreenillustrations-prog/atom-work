## Tropiezos

1. **Lock de git huérfano.** Un `git status` desde el shell del escritorio dejó `.git/index.lock`
   vacío, porque ese shell no puede borrar sin permiso. Se pidió permiso de borrado para la
   carpeta y se eliminó. **Mitigación:** `git --no-optional-locks`.
2. **Primer intento de cambiar los glifos de Ver detalles sin efecto.** El script buscaba la
   etiqueta por nombre de capa y no encontró ninguna; mientras tanto la card ya decía
   `info-circle`. Se rehízo buscando por el texto «Ver detalles» y se verificó con captura.
3. **La consola de Campañas se trabó** dos veces: después de un bloqueo de pantalla (el Return
   se rechazaba con «text is selected») y con un `findAll` sobre toda la página. Se resolvió
   cerrando y reabriendo la pestaña.
4. La Mac se bloqueó dos veces durante la sesión. La pestaña del archivo *Pausado y reactivación
   de envíos de Campañas* quedó abierta en Figma.
